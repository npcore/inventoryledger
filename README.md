# 재고수불 관리 (inventoryledger)

엔피코어 원재료 재고를 분기마다 결산하는 사내 웹 앱입니다. 기존 엑셀 「재고수불 결산파일」로 하던 작업을 그대로 옮겼습니다.

## 결산 방식 (기존 엑셀과 동일)

- **총평균법**: 평균단가 = (기초금액 + 입고금액) ÷ (기초수량 + 입고수량)
- **출고는 실사로 역산**합니다. 출고수량 = 기초 + 입고 − 타계정대체 − 실사수량이고, 출고금액이 매출원가가 됩니다
- 대체금액과 기말금액은 평균단가 × 수량을 원 단위로 반올림합니다. 반올림 차이는 매출원가에 흡수되므로 `기초 + 입고 = 대체 + 출고 + 기말`이 원 단위까지 정확히 맞습니다
- 보관처는 본사, 용인, 성남입니다. 보관처 이동은 금액에 영향이 없고, 실사할 때 참고하는 예상수량에만 반영됩니다

## 분기 결산 순서

1. 분기 중에 **입고**와 **타계정대체**를 등록합니다. 입고는 엑셀로 한꺼번에 올릴 수도 있습니다
2. 분기말에 **재고실사**에서 보관처별 수량을 입력합니다
3. 회계 프로그램에서 받은 **분개장**을 올려 입고장과 대사합니다
4. **수불부**를 확인하고 **마감**합니다. 기말재고가 다음 분기 기초로 확정되고, 그 기간은 더 이상 수정할 수 없습니다
5. **엑셀 다운로드**: 수불부, 재고실사, 입고장, 타계정대체, 보관처이동, 분개장 시트가 기존 양식대로 만들어집니다

처음 쓸 때는 관리자 계정을 만든 뒤 [결산] 메뉴에서 기존 결산파일(.xls)을 한 번 가져옵니다. 가장 최근 `수불부(YYYY.MM)`의 기말재고가 다음 분기의 기초재고가 됩니다.

## 실행

사내 리눅스 서버 설치(Docker)는 [docs/설치-리눅스-도커.md](docs/설치-리눅스-도커.md)를 보세요. 개발용으로 실행할 때는 다음과 같습니다.

```bash
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```

- 데이터는 `data/inventory.db`(SQLite) 파일 하나에 저장됩니다. **이 파일만 백업하면 됩니다**
- 환경 변수: `INVENTORY_DATA_DIR`(데이터 폴더), `INVENTORY_SECRET`(세션 키. 없으면 `data/secret.key`를 자동 생성)
